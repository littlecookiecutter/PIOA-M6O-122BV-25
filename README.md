# Лабораторная работа №2: In-Memory база данных

## Структура проекта
```
src/
└── db/
    ├── backend/
    │   ├── __init__.py
    │   ── memory.py      # Хранение данных, CRUD, валидация типов, схемы таблиц
    ├── __init__.py
    ├── __main__.py        # Точка входа (запуск интерфейса)
    └── tui.py             # Консольный интерфейс (меню, ввод/вывод, обработка команд)
README.md
```

## Реализованный функционал
- Создание и удаление таблиц с динамической схемой
- Поддержка типов данных: `str`, `int`, `float` (указываются при создании таблицы)
- Автоматическая генерация уникального `id` для каждой записи
- CRUD-операции над записями
- Фильтрация записей по любому полю схемы
- Валидация типов данных при вводе и обновлении
- Обработка некорректного ввода и ошибок обращения к несуществующим таблицам/записям
- Текстовый интерфейс с пошаговым вводом значений полей

## Запуск проекта
   ```bash
   python -m src.db
   ```
