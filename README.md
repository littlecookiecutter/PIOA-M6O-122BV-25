## Лабораторная 1: Git и работа с ветками
Выполнены базовые операции Git, дополнительные задачи по squash, revert, merge, cherry-pick и rebase.

## Лабораторная 2: In-Memory база данных (процедурная реализация)
Прототип базы данных, работающей в оперативной памяти. Реализован консольный интерфейс, динамические схемы таблиц, валидация типов данных.

## Лабораторная 3: ООП и тестирование
Рефакторинг СУБД в объектно-ориентированную архитектуру с применением TDD.

### Структура проекта
```
PIOA-M6O-122BV-25/
├── src/db/
│   ├── backend/
│   │   ├── __init__.py
│   │   ├── errors.py          # Пользовательские исключения
│   │   └── memory.py          # Ядро БД (классы Database, Table)
│   ├── __init__.py
│   ├── __main__.py            # Точка входа
│   └── tui.py                 # Консольный интерфейс (класс DatabaseApp)
├── tests/
│   ├── __init__.py
│   └── test_memory.py         # Тесты (unittest)
└── README.md
```

### Реализованный функционал
- Классы `Database` и `Table` вместо глобальных функций
- Динамическая схема таблиц с поддержкой типов: `str`, `int`, `float`, `bool`, `int_pos`, `int_neg`, `float_pos`, `float_neg`
- Автоматическая генерация уникального `id`
- CRUD-операции над записями
- Фильтрация и сортировка записей по любому полю
- Валидация типов и семантических ограничений на уровне ядра
- Пользовательские исключения (`errors.py`)
- Автоматизированные тесты (`unittest`), покрытие backend >80%
- Консольный интерфейс в ООП-стиле (`DatabaseApp`)

### Запуск приложения
Требуется Python 3.9+
```bash
python -m src.db
```

### Запуск тестов и проверка покрытия
Требуется: `pytest`, `pytest-cov`
```bash
# Установка зависимостей (если не установлены)
pip install pytest pytest-cov

# Запуск тестов с отчётом по покрытию
pytest tests/ --cov=src --cov-report=term-missing
```
Цель: покрытие модуля `src/db/backend` не менее 80%.
